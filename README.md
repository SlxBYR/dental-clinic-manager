# 口腔诊所管理系统

面向小型口腔诊所的本地桌面管理软件，用于管理患者档案、处置记录、预约日程、统计报表、数据备份和同步。

当前版本：`v1.3.0`

## 总览

- 显示患者总数、今日预约数和今日预约列表。
- 今日预约可直接切换状态，已取消预约不可继续切换。
- 点击预约记录可进入对应患者详情。
- 今日无预约时提供新建预约入口。
- 展示近 26 周处置完成贡献墙，便于快速查看近期业务活跃度。

## 患者管理

- 新增、查看、编辑和删除患者档案。
- 患者档案包含姓名、电话、性别、年龄、处置记录和预约历史。
- 支持按姓名、电话、拼音全拼和拼音首字母搜索患者。
- 患者列表支持分页和虚拟滚动，大量患者数据下仍能保持较快浏览速度。
- 同一电话号码可对应多个独立患者，适合家属共用电话的场景。
- 同号码患者会在列表中显示同号码组人数。
- 新增患者时会提示相似姓名，便于避免重复建档。
- 删除患者时只清理明确关联该患者的预约，不误删同号码其他患者的数据。

## 处置记录

- 为患者新增、编辑和删除处置记录。
- 处置记录包含处置日期、项目、价格、牙位和备注。
- 处置项目来自设置中的项目目录。
- 新增和编辑处置时会带出当前目录价格，同时允许手动改价。
- 支持牙位为空。
- 牙位选择支持恒牙、乳牙、全口、上颌和下颌。
- 同一牙位的恒牙和乳牙互斥选择。
- 编辑处置记录时自动生成修改日志，只记录实际变化字段。
- 可查看处置修改时间、修改字段、修改前值和修改后值。

## 预约管理

- 新建、编辑、取消和删除预约。
- 每条预约都有独立唯一 ID。
- 预约状态包括待诊、完成和已取消。
- 取消预约会保留记录，并将状态改为已取消。
- 新建和编辑预约时会进行时间冲突检查。
- 当前冲突规则为同一日期、同一时间不能存在另一条未取消预约。
- 修改预约时会排除自身记录，避免自己与自己冲突。
- 预约变更会同步更新患者详情中的预约历史。

## 统计报表

- 展示总收入、今日收入、本月收入、近 30 天处置数量和近 30 天收入。
- 展示项目收入排行。
- 展示项目处置次数排行。
- 展示活跃患者统计。
- 点击活跃患者可进入患者详情。
- 无处置记录时显示空状态。

## 设置与数据

- 修改诊所名称。
- 管理处置项目目录，支持分类和项目的新增、编辑、删除。
- 导出患者、处置、预约、目录和设置数据为 JSON。
- 导入 JSON 前会进行数据迁移和结构校验。
- 导入前会显示预览，包含患者、预约、处置和目录的新增、覆盖、移除数量。
- 导入成功前会保存本机导入前备份。
- 可恢复最近一次导入前备份。
- 配置备份接口，并向服务器发送完整备份数据。
- 配置云端同步接口，通过同步 Key 拉取或上传数据。
- 配置 GitHub Release 接口，支持自动检测和手动检测新版本。

## 本地数据

- 桌面端优先使用 SQLite 保存数据。
- SQLite 内部按患者、处置、处置修改日志、预约、项目目录和设置拆表保存。
- 保留兼容数据快照，支持现有导入、导出、备份和同步流程。
- 浏览器预览或 SQLite 不可用时会回退到 localStorage。
- 卸载应用默认不删除患者、预约和处置数据。

## Windows 辅助功能

- Windows 安装器会在安装和卸载前尝试关闭正在运行的 `DentalSystem.exe`。
- 提供 Windows 卸载辅助脚本，用于处理旧版本残留、卸载器缺失或卸载注册表损坏。
- 卸载辅助脚本默认保留用户数据。
- 只有明确传入删除用户数据参数时，才会删除本机应用数据目录。
